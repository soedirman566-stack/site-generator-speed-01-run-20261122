## About

An entry for the make.fun bounty **site-generator-speed-01-run-20261122**: a
fast, dependency-free reimplementation of makefun-site 1.0.0's static site
build. `solve.js` exports `run(input)`, which returns the reference build's
output tree byte for byte — front matter, permalinks, the Markdown subset,
collections and tags, the template dialect and `build-report.txt` — and
`main.ts` is the harness driver that answers every case in
`/input/cases.json` into `/output/answers.json`.
